The **Probability Mass Function (PMF)** defines the probability distribution of a **discrete** random variable.

## Definition

For discrete RV X, the PMF is:
$$p(x) = P(X = x)$$

**Requirements:**
1. p(x) ≥ 0 for all x
2. Σₓ p(x) = 1

## Examples in Public Health

**Number of ANC visits (discrete counts):**

| x (visits) | p(x) |
|-----------|------|
| 0 | 0.12 |
| 1 | 0.08 |
| 2 | 0.15 |
| 3 | 0.18 |
| 4+ | 0.47 |

**Skilled birth attendance (binary):**
- P(X=1) = 0.67 (with skilled attendant)
- P(X=0) = 0.33 (without)

## Common PMFs

**Bernoulli:** One trial, P(X=1) = p
$$p(x) = p^x(1-p)^{1-x}, \quad x \in \{0,1\}$$

**Binomial:** n trials, P(X=k) = k successes
$$p(k) = \binom{n}{k}p^k(1-p)^{n-k}$$

**Poisson:** Count of rare events in fixed interval
$$p(k) = \frac{e^{-\lambda}\lambda^k}{k!}$$

## PMF vs PDF vs CDF

| Function | For | Gives |
|----------|-----|-------|
| PMF | Discrete | P(X = x) |
| PDF | Continuous | Density at x |
| CDF | Both | P(X ≤ x) |

```python
from scipy.stats import binom, poisson
import matplotlib.pyplot as plt
import numpy as np

# Binomial PMF: n=10 ANC visits target, p=0.67 compliance
n, p = 10, 0.67
x = np.arange(0, 11)
pmf_vals = binom.pmf(x, n, p)

plt.bar(x, pmf_vals, color='steelblue', alpha=0.8)
plt.xlabel('Number of women with ≥4 ANC visits')
plt.ylabel('P(X = x)')
plt.title('Binomial PMF (n=10, p=0.67)')
plt.show()

# Poisson PMF: maternal deaths per district (λ=2.3)
lam = 2.3
k = np.arange(0, 10)
plt.bar(k, poisson.pmf(k, lam), color='coral')
plt.title(f'Poisson PMF (λ={lam})')
plt.show()
```
